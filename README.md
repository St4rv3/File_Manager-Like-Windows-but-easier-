# STABLE TASK MANAGER v5.0

Консольный системный монитор и менеджер процессов с цветным интерфейсом. Поддерживает два режима работы: полный UI (prompt_toolkit) и терминальный режим.

![Demo](demo.gif)

## 📦 Возможности

### Основные
- 📊 **Мониторинг системы** — CPU, RAM, диск, сеть в реальном времени
- 📈 **График истории CPU** — визуальный ASCII-график загрузки
- 💾 **Детали памяти** — используемая/доступная память в GB
- ⏱ **Uptime** — время работы системы
- 🔢 **Информация о CPU** — количество ядер

### Управление процессами
- 🔍 **Поиск** — фильтрация процессов по имени
- 🎯 **Сортировка** — по CPU, памяти, имени, PID
- ⬆️⬇️ **Прокрутка** — постраничный просмотр всех процессов
- ❌ **Kill** — завершение процессов по PID

### Данные и экспорт
- 💾 **Логирование** — сохранение метрик в SQLite
- 📤 **Экспорт CSV** — выгрузка логов
- 🧹 **Очистка** — удаление старых записей
- ⚙️ **Конфигурация** — настройки в config.json

## 📁 Файлы

| Файл | Описание |

## 🖥️ Требования

- Python 3.8+
- psutil
- prompt_toolkit (для main.py)

## ⚡️ Установка

```bash
pip install psutil prompt_toolkit
```

## 🚀 Запуск

### Вариант 1: main_input.py (рекомендуемый для VS Code)
```bash
python main_input.py
```

Команды:
- `/текст` — поиск процессов (например: `/python`)
- `k PID` — завершить процесс (например: `k 15372`)
- `число` — завершить процесс по PID
- `w` — страница вверх
- `s` — страница вниз
- `r` — сбросить фильтр
- `q` — выход

### Вариант 2: main_terminal.py (для Windows Terminal / cmd)
```bash
python main_terminal.py
```

Горячие клавиши:
- `/` — режим поиска
- `k` — режим kill
- `w/s` — прокрутка
- `r` — сбросить
- `q` — выход
- `ESC` — отмена

### Вариант 3: main.py (полный UI)
```bash
python main.py
```
Требует Windows Terminal или cmd.exe с поддержкой полноэкранного режима.

## ⌨️ Управление (main.py)

| Клавиша | Действие |
|--------|---------|
| `←`/`→` | Переключение страниц |
| `/` | Фильтр по имени |
| `N` | Фильтр по PID |
| `r` | Сброс фильтра |
| `s` | Сменить сортировку |
| `Пробел` | Направление сортировки |
| `k` | Kill процесс |
| `K` | Kill дерево процессов |
| `F1` | Справка |
| `q` | Выход |

## 📊 Страницы

### PROCESSES
Список процессов с PID, именем, CPU%, MEM%, DISK I/O

### SYSTEM
- Прогресс-бары CPU, RAM, DISK
- График истории CPU
- Uptime, ядра CPU
- Сеть (↑/↓)

### NETWORK
- TCP/UDP соединения
- Фильтр по порту

### LOGS
История метрик из БД

### HELP
Справка

## 🗄️ База данных

| Поле | Тип |
|------|-----|
| id | INTEGER |
| timestamp | TEXT |
| cpu | REAL |
| memory | REAL |
| disk_percent | REAL |
| net_sent | INTEGER |
| net_recv | INTEGER |
