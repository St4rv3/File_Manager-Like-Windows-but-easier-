# Stable Virtual Task Manager v4.1

Консольный системный монитор и менеджер процессов с цветным интерфейсом на базе `prompt_toolkit`. Работает без ANSI‑мусора, устойчив к ошибкам и поддерживает логирование в SQLite.

![Демо](demo.gif) *(если есть гифка – замените ссылку)*

## 📦 Возможности

- 🖥 **Мониторинг процессов** – сортировка по PID, имени, CPU, памяти, фильтрация по названию
- 📊 **Системные ресурсы** – прогресс-бары CPU и RAM, использование диска и сети
- 🌐 **Сетевые соединения** – список слушающих TCP‑портов
- 📝 **Логирование метрик** – сохранение CPU, MEM, диска, трафика в SQLite
- 🎮 **Полностью клавиатурное управление** – горячие клавиши для навигации и действий
- 🚫 **Никакого ANSI‑мусора** – чистый вывод через родные стили `prompt_toolkit` (не требует Rich)
- 💪 **Стабильность** – корректная работа с правами обычного пользователя, миграция базы данных при обновлении, обработка ошибок

## 🗝️ Горячие клавиши

| Клавиша      | Действие                                 |
|--------------|------------------------------------------|
| `←` / `→`    | Переключение страниц (PROCESSES → SYSTEM → NETWORK → LOGS → HELP) |
| `/`          | Фильтр процессов по имени (ввод строки)  |
| `r`          | Сброс фильтра                            |
| `s`          | Изменить сортировку: CPU → MEM → NAME → PID |
| `k`          | Завершить процесс по PID                 |
| `F1`         | Показать справку                         |
| `q`          | Выход из программы                       |

## 📋 Страницы мониторинга

### PROCESSES
- Список запущенных процессов (PID, имя, CPU%, MEM%, статус)
- Цветовые индикаторы: 🟢 зелёный (низкая нагрузка), 🟡 жёлтый (средняя), 🔴 красный (высокая)
- Поддержка фильтрации: введите `/python` чтобы увидеть только процессы Python
- Сортировка по любому столбцу

### SYSTEM
- Прогресс‑бары CPU и RAM
- Текущая загрузка диска в процентах
- Объём переданных/принятых данных по сети (в КБ)

### NETWORK
- Вывод TCP‑соединений в состоянии LISTEN (локальный адрес и PID)
- Может потребовать прав администратора для корректного отображения всех процессов

### LOGS
- Последние 10 записей из базы данных `metrics.db`
- Временные метки, CPU, MEM с цветовыми индикаторами

### HELP
- Встроенная справка по управлению

## 🗃️ База данных

Программа автоматически создаёт (или мигрирует) файл `metrics.db` в текущей директории.  
Структура таблицы `system_metrics`:

| Поле          | Тип     | Описание                                  |
|---------------|---------|-------------------------------------------|
| id            | INTEGER | Первичный ключ                            |
| timestamp     | TEXT    | ISO‑дата/время записи                     |
| cpu           | REAL    | Загрузка CPU в процентах                  |
| memory        | REAL    | Использование оперативной памяти в %      |
| disk_percent  | REAL    | Загрузка диска в % (добавляется при миграции) |
| net_sent      | INTEGER | Отправлено байт (добавляется при миграции) |
| net_recv      | INTEGER | Получено байт (добавляется при миграции)  |

При первом запуске таблица создаётся с базовыми полями, недостающие колонки добавляются автоматически при обновлении программы.
